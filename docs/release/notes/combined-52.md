Earth Platform build 52: no more dark walls or holes around spawn with shaders.

**Play in a fresh world.** Give the game about 6 GB of memory with Photon.

Needs Minecraft 1.21.1 and NeoForge 21.1.256 or newer. For shaders, add Iris 1.8 and Sodium 0.8 and the stock Photon v1.3b pack.

New since build 51:
- With a shader pack, right after arriving somewhere new (while "Downloading Earth data" still shows), far terrain fills in close to the player before the game's blocks load. Since build 48 those close far blocks drew as a huge dark striped wall, with stretched grass and leaves and white holes around spawn, on Mac and Windows. Far terrain inside the game's own block range now draws as it did in build 47, and only far terrain past the edge of the game's blocks keeps build 48's step-by-step shadows. Far terrain stays blocky and stripe-free.

Not yet tested in a real VR headset.

Known: dark far slabs can show in the Amazon for the first ~20 seconds; Everglades far water is still patchy.
