Earth Platform build 40: far terrain fills in faster.

**Play in a fresh world.** Give the game about 6 GB of memory with Photon.

Needs Minecraft 1.21.1 and NeoForge 21.1.256 or newer. For shaders, add Iris 1.8 and Sodium 0.8 and the stock Photon v1.3b pack.

New since build 39:
- Far terrain fills in faster: on a first visit to Mount Shasta the far ring was done in about 146 seconds instead of 272, and far work in places already visited takes 15 to 27% less time. The terrain itself is unchanged.
- No more blue cut-out below the cliffs at Yosemite: creeks running down steep slopes now keep to the slope instead of cutting a trench 25 blocks under it.
- When an Earth data host is down, the server no longer crashes as you walk into new ground. A dead host is noticed within seconds, a banner says so, and travel tells you right away instead of stalling; everything loads once the host is back.
- No more square pits and 50-block trenches along shallow coasts such as the Exumas: stray 0 m spots in the elevation data are no longer mistaken for open sea.

Known: dark far slabs can show in the Amazon for the first ~20 seconds; Everglades far water is still patchy.
