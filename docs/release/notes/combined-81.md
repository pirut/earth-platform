Earth Platform build 81 fixes invisible Create machines.

Requires Minecraft 1.21.1 with NeoForge 21.1.256 or newer, or Fabric Loader 0.16.14 or newer with Fabric API. Optional mods may require newer loader versions.

### Fixes

- Create machines (shafts, cogwheels, belts and other moving parts) now show up in the Earth again after you rejoin, travel, or reload resources. They used to be invisible unless you placed them while watching (#288).
- Machines relight properly when you place or remove a torch nearby.

### Note

- If you used `/flywheel backend flywheel:off` as a workaround, you can switch back with `/flywheel backend flywheel:indirect`.
