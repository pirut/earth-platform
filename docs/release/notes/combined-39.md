Earth Platform build 39: far terrain that fades between detail levels, and a sharpness setting.

**Play in a fresh world.** Give the game about 6 GB of memory with Photon.

Needs Minecraft 1.21.1 and NeoForge 21.1.256 or newer. For shaders, add Iris 1.8 and Sodium 0.8 and the stock Photon v1.3b pack.

New since build 38:
- Far terrain sharpness: Fast, Balanced (the default), Sharp or Sharpest. Change it from the pause menu in Earth worlds (next to Mods) or in Earth Settings; it takes effect right away. Sharper costs more memory and frame time; Fast is lighter.
- Far terrain levels now fade into each other instead of meeting at a visible seam.
- When a data host asks us to slow down, every download from it now waits as asked instead of retrying quickly.

Known: dark far slabs can show in the Amazon for the first ~20 seconds; Everglades far water is still patchy.
