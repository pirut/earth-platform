Earth Platform build 68: far terrain sharpens when you zoom, and block-breaking cracks show again on high ground.

Needs Minecraft 1.21.1 and either NeoForge 21.1.256 or newer, or Fabric Loader 0.16.14 or newer with Fabric API. For shaders, add Iris 1.8 and Sodium 0.8 and a Voxy-capable pack such as Photon v1.3b. Give the game about 6 GB of memory with shaders.

New since build 67:
- The cracks on a block you're breaking show again above Y 2,047, on both the NeoForge and Fabric builds. Minecraft keeps cracks under a packed position that wraps above Y 2,047, so Earth remembers each crack's real place. It forgot that place after the first crack stage, so every later stage was drawn thousands of blocks away and you saw no cracks at all on most mountains. It now keeps the place through every stage.
- Far terrain now sharpens where you zoom in, with a spyglass, a zoom mod like Zoomify, or a narrow field of view. Far terrain gets coarser with distance from you, so zoomed in on a mountain 8 km away you saw big flat blocks and seams between them. Zoomed in, Earth now loads the finer terrain a player standing much nearer would see, evenly across your whole zoomed view, coarse to fine from the middle out, and skips ground hidden behind hills so even strong zoom fits. It sharpens over a few seconds; at very strong zoom over open ground it sharpens as far as fits in memory. This costs extra downloads and memory only while you're zoomed; normal play is unchanged. Servers need build 68 too to send the finer terrain; on an older server zoom looks as before. Turn it off with `-Dearthplatform.far.zoom=false`.
- Server owners can choose where the web map answers with the new `webMapAddress` setting (in the config file, the config screen and `/earth settings`). The default `0.0.0.0` answers on every network as before; `127.0.0.1` keeps the map on the server's own computer. An address that isn't an IP address leaves the map off and says why in the log, once.
- The guessing-game setting is now called `whereOnEarth` ("Where on Earth rounds"). It starts on; if you had switched the old `geoguessr` setting off, switch this one off again.
- Both jars now carry CREDITS.md and THIRD_PARTY_NOTICES.md in META-INF, next to the licence.
