# Detailed elevation sources

Where a country or region publishes a fine terrain model, Earth Platform downloads it while you play through [Mapterhorn](https://mapterhorn.com), which gathers these open national models into one tile set. Nothing from these sources is bundled in the mod. The table lists every source Mapterhorn uses, copied from its [attribution.json](https://download.mapterhorn.com/attribution.json) on 2026-10-13 (151 sources); the live file is the reference if they differ.

Changes: the mod blends these heights with the global elevation tiles, smooths the seams between them and turns the result into Minecraft terrain. No source endorses Earth Platform.
