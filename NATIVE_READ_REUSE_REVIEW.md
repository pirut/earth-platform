## Authority and physical ownership

A native mesh retains a strict primary published Job and a bounded immutable footprint of observed facade inputs. A neighboring revision can acquire a new Job only within the same live world, connection epoch, XYZ lease and resource generation. Changed owners replay exact getter values; unchanged current Jobs do not replay. State/FluidState identities and scalar bits are compared, with model data, light, tint, shade and envelope contracts explicit. The fixed tint resolver is never invoked or retained. Unsupported auxiliary light/global membership and unknown reads poison compilation even when caught by a model. The explicit one-cube halo rejects stage-only far reads before dependency preparation.

Preparation creates a private metadata-only Reuse. It cannot change current or historical binding and allocates no GL object. The existing frame fence orders exact candidate validation, server-allowed far commit, historical ticket retirement, fresh native binding activation, obsolete physical mesh retirement and PAIR_READY. Only the subsequent exact server COMMITTED receipt publishes collision. A failure at any intermediate step hides/fences the pair and attempts all retained cleanup owners.

The physical VBO budget remains55 and source coordinate union213. Pending reuse contains references to existing immutable payloads only. Identity-deduplicated reporting includes replica snapshots, physical mesh bindings, pending old/new bindings, the active build's whole immutable neighborhood, and historical presentation. A serialized edit can add one prior pin snapshot: the conservative identity limit214 is distinct from the coordinate limit213. Actual supported phase maxima are213 during movement or153 during an edit with a disjoint pin. Encoded section bytes and declared footprint accounting units are not JVM heap measurements.

## Bounded work

One stale mesh is classified per AFTER_LEVEL frame, returning before native model work. A footprint holds at most32768 distinct observations, and one preparation compares at most32768 values. Overflow clears the recorder and disables reuse for that mesh rather than growing metadata. Repeated isCurrent/commit calls check immutable Job/appearance metadata without another replay. One active builder remains allowed. Native model callbacks, finish/upload, GL calls and some bookkeeping remain indivisible soft-budget operations.

The original baked-model iteration stays on the render owner. Renderer identity, options/config and resource generation remain strict. An observed appearance mismatch permanently rejects the mesh. An unobserved options A→B→A between checks cannot be detected without an external monotonic options generation; no universal third-party model side-effect or broad compatibility claim is made. This gate keeps the accepted local opaque/cutout model path and diagnostic illumination.

## Far geometry

Within one immutable view/world/source/epoch/resource/center, an identical sorted XYZ ready-mask set can reuse committed immutable far Geometry. Every request still obtains a fresh full lease/revision authority ticket and generation. Preparation does not publish, server ALLOW remains mandatory, and commit revokes the old presentation. A changed mask/source/identity cannot use this path. No new payload, CPU job, cache entry or mesh owner is created by a same-geometry hit. Initial compilation and changed-mask preparation retain their bounded background paths.
