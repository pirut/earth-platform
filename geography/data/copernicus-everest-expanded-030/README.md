# Retained Copernicus expansion for 030

Strictly offline expansion of the already retained original source block. No new source download, interpolation, height correction, rescaling or source padding is written into this pack. All 528 x 1024 valid posts are retained, with original 1 arcsecond PixelIsPoint registration and EGM2008 metre heights. The original 180 x 180 proof crop is bit-identical.

Original source bytes, XML and license files remain in ../copernicus-everest-proof. import-report.json records all seven verified original artifact hashes and the original source-lock hash. See that directory for source and license URLs.
